# Scene Review Tool

本工具用于对遥感图像-mask 数据集进行本地人工审查和场景精选。

## 启动

在项目根目录运行：

```powershell
$env:PYTHONPATH="src"
python -m scene_review_tool
```

## 当前初版已支持

- 默认使用“通用图像-Mask文件夹”导入，只需分别选择两个文件夹。
- 通用模式支持同名 stem 配对，以及相对路径 + stem 配对。
- 遇到重复 stem 时停止猜测配对，并在扫描结果中报告歧义。
- VOC segmentation 作为独立导入方式，可按 `all/train/val/test` 清单选择样本。
- 正式导入前可扫描配对数量、警告、抽样 mask 值和尺寸问题，并预览首组叠加结果。
- 可配置 mask 前景标签值；多个值使用英文逗号分隔。
- 显示原图与二值 mask 叠加。
- 勾选显示/隐藏 mask，调节透明度。
- 逐图选择质量状态。
- 场景体系 JSON 为可选项；提供有效体系时可选择一级/二级场景。
- 未提供场景体系时默认使用数据集自定义场景。
- 从当前数据集已使用场景中快速复用。
- 添加并保留当前数据集自定义场景。
- “当前数据集常用场景”中的数量表示当前已有多少样本被分配到该场景，不是点击次数。
- 点击常用场景只会填入右侧场景选择候选，点击“确认场景”后才保存。
- SQLite 自动保存进度。
- 导出统计 CSV，使用 UTF-8 BOM，Excel 直接打开不乱码。
- 导出全部 accepted 样本，不要求完成场景划分。
- 将 accepted、场景状态为 assigned 且场景名有效的样本按场景复制导出。
- 导出前显示数量预览，导出清单记录质量状态和场景状态。

## 导入其他数据集

普通图像-mask数据集优先选择“通用图像-Mask文件夹”。平铺目录选择“同名文件”；两侧存在镜像子目录且不同子目录可能出现相同文件名时，选择“相对路径与文件名均相同”。

项目导入页不会预填本机路径，请根据界面提示选择数据集与工作区。场景体系 JSON 可以留空，此时进入审查页后直接填写自定义场景；如果选择了有效的体系 JSON，则可以在正式体系与自定义场景之间切换。

先点击“扫描预览”，确认配对数量、mask值、场景模式和首组叠加图正确，再点击“导入并开始审查”。若工作区已有 `review.sqlite3`，使用“打开已有工作区”继续，程序不会重复导入覆盖已有进度。旧工作区引用的体系文件在当前电脑不存在时，已有记录仍会保留，程序改用自定义场景模式继续运行。

## 说明

当前版本是 UI 初版，重点验证人工精选流程是否顺手。TIFF/GeoTIFF 高位深显示、多类别 mask 图例、缩略图缓存和后台预加载属于下一阶段优化。
