# Scene Review Tool

本工具用于对遥感图像-mask 数据集进行本地人工审查和场景精选。

## 启动

在 `D:/硕士毕业论文/scene_review_tool` 目录运行：

```powershell
$env:PYTHONPATH="src"
python -m scene_review_tool
```

## 当前初版已支持

- 默认使用“通用图像-Mask文件夹”导入，只需分别选择两个文件夹。
- 通用模式支持同名 stem 配对，以及相对路径 + stem 配对。
- 遇到重复 stem 时停止猜测配对，并在扫描结果中报告歧义。
- VOC segmentation 作为独立导入方式，可按 `all/train/val/test` 清单选择样本。
- 正式导入前可扫描配对数量、警告、抽样 mask 值和尺寸问题，并预览首组叠加结果。
- 可配置 mask 前景标签值；多个值使用英文逗号分隔。
- 显示原图与二值 mask 叠加。
- 勾选显示/隐藏 mask，调节透明度。
- 逐图选择质量状态。
- 从 `geo_scene_taxonomy_1.0.json` 选择一级/二级场景。
- 从当前数据集已使用场景中快速复用。
- 添加并保留当前数据集自定义场景。
- “当前数据集常用场景”中的数量表示当前已有多少样本被分配到该场景，不是点击次数。
- 点击常用场景只会填入右侧场景选择候选，点击“确认场景”后才保存。
- SQLite 自动保存进度。
- 导出统计 CSV，使用 UTF-8 BOM，Excel 直接打开不乱码。
- 将 accepted 且已分场景样本按场景复制导出。

## 当前绿地数据集

默认表单已填入城市绿地 512 数据：

```text
D:/硕士毕业论文/相关图文数据集/自有数据集/greenland_3968x3968_test512
```

可以直接使用默认的通用导入方式：

```text
图像文件夹 = 数据集根目录/JPEGImages
Mask文件夹 = 数据集根目录/SegmentationClass
配对规则 = 同名文件（忽略扩展名）
```

也可以切换为VOC导入方式：

```text
VOC根目录 = 数据集根目录
数据划分 = all
图像目录名 = JPEGImages
Mask目录名 = SegmentationClass
```

该数据集 mask 为二值灰度图：`0` 表示背景，`1` 表示绿地前景。界面叠加时会将值大于 0 的区域以青色显示。

## 导入其他数据集

普通图像-mask数据集优先选择“通用图像-Mask文件夹”。平铺目录选择“同名文件”；两侧存在镜像子目录且不同子目录可能出现相同文件名时，选择“相对路径与文件名均相同”。

先点击“扫描预览”，确认配对数量、mask值和首组叠加图正确，再点击“导入并开始审查”。若工作区已有 `review.sqlite3`，使用“打开已有工作区”继续，程序不会重复导入覆盖已有进度。
